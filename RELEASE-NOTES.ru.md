# Acer Control 0.1.0-rc12

## Dashboard

- Перебалансирована вертикальная компоновка главного окна, чтобы график истории получил существенно больше полезной высоты.
- Селектор **профиля управления вентиляторами**, строка фактически активного профиля и кнопка **Настройки профиля** перенесены в ранее свободную нижнюю левую область под состоянием NVIDIA GPU.
- Управление platform profile и подсветкой клавиатуры оставлено в правой колонке.
- Уменьшены вертикальные отступы без потери информации.
- Минимальная/natural высота графика истории уменьшена с 360 до 260 px; при наличии места он по-прежнему расширяется.
- Стартовая высота Dashboard уменьшена с 850 до 720 px, чтобы окно нормально изменялось по высоте на рабочей области ноутбука.

## Профили вентиляторов

- Platform profile и fan-control profile теперь представлены как два независимых селектора.
- Пользовательские fan profiles можно выбирать непосредственно в Dashboard.
- Поддерживаются и сохраняются режим **Автоматически (следовать профилю платформы)** и ручной выбор fan profile.
- Встроенные системные custom-профили read-only: для редактирования сначала создаётся пользовательская копия.
- Firmware-профили нельзя выдавать за редактируемую копию, потому что Acer firmware не предоставляет их внутренние кривые.

## Редактор и визуализация

- Profile Settings использует независимую прокрутку editor/preview с фиксированными header/footer.
- Preview выходного уровня вентиляторов использует визуальную шкалу 0..110%, при том что допустимое значение остаётся ограничено 100%.
- График динамики контроллера показывает EMA при росте/снижении, CPU hysteresis, CPU down delay и GPU native down delay.
- История Dashboard использует шкалу температуры 30..110 °C, поэтому реальное значение 100 °C не прилипает к верхней рамке графика.

## Установка и интеграция

- Самостоятельная системная установка в `/usr/local/lib/acer-control`.
- Интеграция D-Bus/polkit/systemd.
- DKMS RGB bridge 0.3 с опциональной постоянной настройкой подписи MOK для Secure Boot.
- GNOME/Freedesktop desktop entries и иконки приложения.
- Обновление поверх предыдущей версии сохраняет локальные настройки и пользовательские профили, одновременно обновляя package-owned встроенные профили.
- Локализация EN/RU с режимом Auto по языку системы.

## Известное ограничение release candidate

Исполнение custom fan profiles пока зависит от ранее разработанного legacy PWM writer `/usr/local/sbin/acer-fan-control`. Новый daemon хранит и валидирует профили, но на чистой установке ещё не выполняет production PWM loop самостоятельно.
