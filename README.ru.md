# Acer Control для Ubuntu на Acer Nitro

[English README](README.md)

Acer Control — центр управления на GTK4/libadwaita для ноутбуков Acer Nitro под Linux. Он объединяет телеметрию, переключение Acer platform profile, управление и визуализацию профилей вентиляторов и аппаратное управление RGB-клавиатурой через привилегированный системный D-Bus daemon.

> **Статус проекта:** release candidate `0.1.0-rc12`. Разработка и аппаратная проверка сейчас ведутся прежде всего на **Acer Nitro AN515-58** с **Ubuntu 26.04**. Другие модели Acer могут использовать другие WMI-методы и поведение прошивки и считаются непроверенными до отдельного тестирования.

## Возможности

- Dashboard GTK4/libadwaita с температурами CPU/GPU, RPM вентиляторов и историей текущего запуска.
- Шкала температуры истории `30..110 °C`, чтобы реальное значение `100 °C` визуально не прилипало к верхней границе графика.
- Переключение ACPI `platform_profile` и сохранение профиля по умолчанию.
- Раздельные селекторы **профиля платформы** и **профиля управления вентиляторами**.
- Библиотека профилей вентиляторов: защищённые системные профили и редактируемые пользовательские копии.
- Интерактивный редактор кривых и симуляция контроллера с отображением EMA, CPU hysteresis, CPU down delay и GPU native down delay.
- Системные профили read-only; custom-шаблон `Performance` можно скопировать в пользовательский профиль и уже копию редактировать.
- 4-зонная RGB-клавиатура с аппаратными эффектами Static, Breath, Neon, Wave, Shifting и Zoom.
- Аппаратный таймаут подсветки клавиатуры, когда он поддерживается firmware-интерфейсом.
- Системный daemon root через D-Bus + polkit; сам GUI запускается от обычного пользователя.
- DKMS-модуль RGB WMI bridge и опциональная настройка подписи MOK для Secure Boot.
- Интерфейс EN/RU с режимом Auto по локали графической сессии.
- Самостоятельный установщик, обновление поверх предыдущей версии, диагностика и удаление.

## Компоновка Dashboard в RC12

RC12 перераспределяет верхнюю часть главного окна по вертикали. Выбор fan-control profile теперь использует свободное место под состоянием NVIDIA GPU, а управление platform profile остаётся справа. За счёт этого график истории получает заметно больше высоты на экране ноутбука, а окно остаётся изменяемым по высоте.

## Platform profile и fan-control profile — разные вещи

- **Профиль платформы** управляет Acer/ACPI `platform_profile`: `low-power`, `quiet`, `balanced`, `balanced-performance`, `performance`.
- **Профиль управления вентиляторами** выбирает policy-профиль Acer Control. Можно включить **Автоматически (следовать профилю платформы)** или выбрать любой встроенный/пользовательский fan profile вручную.

Созданные пользовательские профили появляются в селекторе Dashboard. Ручной выбор сохраняется сразу, а список обновляется при возвращении фокуса в главное окно, поэтому новая копия становится доступна без перезапуска приложения.

## Важное ограничение RC

Текущий daemon обслуживает телеметрию, platform profiles, хранение/редактор профилей и RGB-клавиатуру. Рабочий PWM-loop, разработанный раньше, **ещё не перенесён в daemon**. Если `/usr/local/sbin/acer-fan-control` уже установлен, installer его сохраняет. На чистой системе без legacy writer пользовательские кривые можно редактировать и хранить, но они пока не исполняются. Управление вентиляторами прошивкой и Acer platform profiles продолжают работать.

Это основной архитектурный хвост перед полностью самостоятельным fan-control release.

## Быстрая установка из исходников

```bash
git clone https://github.com/gig1910/ubuntu_acer_nitro_sense.git
cd ubuntu_acer_nitro_sense
sudo ./install.sh
```

Тот же installer используется для обновления поверх предыдущей версии. Существующие `/etc/acer-control/acer-control.conf` и пользовательские профили сохраняются.

Для Secure Boot installer может использовать уже enrolled MOK или настроить DKMS signing интерактивно. Подробнее: [Установка](docs/ru/INSTALLATION.md).

## Сборка самостоятельного `.run`

```bash
./tools/build-release.sh
```

Результат появляется в `dist/`:

```text
acer-control-<version>.tar.gz
acer-control-<version>-installer.run
acer-control-<version>.SHA256SUMS
```

## Диагностика

После установки:

```bash
acer-control-diagnose
```

Полезные ручные проверки:

```bash
systemctl status acer-control-daemon.service
modinfo acer_control_rgb_bridge
cat /sys/kernel/acer_control_rgb/capabilities
busctl introspect org.acer.Control /org/acer/Control org.acer.Control
```

## Аппаратная область

Программа записывает firmware-facing параметры и устанавливает внешний kernel module. Используемые методы проверены на development AN515-58, но это не означает автоматической совместимости со всеми Acer Nitro. Совпадения имени линейки недостаточно.
